# 필기
## 인트로
* 인트로 하얀색 테두리 박스
    1. 테두리 용 div를 하나 만들어 컨테이너 div와 형제가 되게 만들어 준다.
    2. 테두리 div에 position:absolute(피그마에서 오토레이아웃 무시를 사용했음)주고 각 사방(top, bottom, left, right)에 각각 위치를 잡아준다.
* 스크롤 애니메이션
    * 스크롤 위치를 잡을 때 position:absolute로 left:50% 줬을 때, 가운데로 맞추기 위해 transform:translateX(-50%)를 사용하게 되는데, 애니메이션(위아래로 움직이게 함)을 적용 시 transform이 풀려버리게 되는 문제가 발생
        * 이 경우, index.css에 적은 transform을 지우고 애니메이션에 같이 적어주면 된다.
## 프로필
* 오른쪽 이력서의 작은 섹션 가로 비율
    * 프로필의 부모에도 자식에도 display:flex, justify-content:space-between가 들어갈 때 자식의 비율을 맞추고 싶다면 flex:1 사용
        * 다만 원하는 간격이 나오지 않으면 자식에게 고정 gap 값을 주면 된다.
* 키워드의 가로 세로 간격이 다를 경우 gap 값
    * gap에 두 값을 쓰기 -> 첫번째 값은 상하 간격, 두번째 값은 좌우 간격
        예) gap:15px, 10px; => 상하 15px, 좌우 10px
## 웹사이트 리디자인
* word-break:keep-all; -> 글자가 예쁘게 줄바꿈 하게 하는 속성
